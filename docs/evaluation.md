# 編集の正しさの評価（#345 D7）

実際の素材で「無音を削る」「話の区切りで分ける」「場面ごとに切る」「字幕を付ける」を、
人の編集（正解）と比べて、一致率とかかった時間を数える 変更の前と後で数を比べ、
精度が上がったか下がったかを確かめる

台本は `tools/eval_tasks.py` 今あるのは**道具の段**（AI を通さず、編集の道具が使う
処理を直に呼ぶ）だけ AI に指示を出して測る段は後で足す

## 決まり

- 素材・正解・直す用の .sme は**リポジトリの外**のフォルダに置く リポジトリの中を指すと台本が止まる
- リポジトリでは素材を番号（E04 など）だけで呼ぶ 番号と実物の対応表は外のフォルダの `manifest.json` だけに書く
- リポジトリに入れるのは、台本・課題の定義（`eval/tasks.json`）・数えた結果（`eval/results/tools.jsonl`）だけ
- 結果を書く前に、台本が素材の名前・置き場のフォルダ名・日本語の文が混じっていないかを確かめる 混じっていれば 1 行も書かずに止まる
- 使う素材は本人が自分で撮った・作った物だけ 本人が候補を見て決めた
- Issue・PR・コミットに素材の名前や置き場を書かない

## 用意

1. 外のフォルダを作る（例 `D:\sashimono-eval`） 中に `manifest.json` を置く

   ```json
   {"E04": "D:/どこか/素材その1.mp4", "E05": "D:/どこか/素材その2.mp4"}
   ```

   相対の場所は、このフォルダから読む
2. 環境変数 `SASHIMONO_EVAL_DIR` にそのフォルダを入れる（または、命令ごとに `--dir` で指す）
3. 字幕の課題には字幕起こしの実行環境（faster-whisper）が要る 入っていなければ、字幕の
   課題は下書きも数えるのも飛ばし、結果に `asr-missing` と残す

## 流れ

```
.venv\Scripts\python.exe tools\eval_tasks.py draft          # 仮の正解と直す用の .sme を作る
（本人が .sme を開いて直す 下の「正解を直す」）
.venv\Scripts\python.exe tools\eval_tasks.py adopt E09 scenes   # 直した .sme を正解にする
.venv\Scripts\python.exe tools\eval_tasks.py run            # 道具を走らせて比べ、結果を足す
.venv\Scripts\python.exe tools\eval_tasks.py report         # 課題ごとに前回との差を出す
```

`run` には `--silence-threshold-db` や `--scene-threshold` などで道具の値を変えて回せる
既定値を変えるか迷ったときは、変える前と後で 1 回ずつ回して差を見る

### 仮の正解

本人が直すまでは、道具の下書きをそのまま正解（仮の正解）として使う 結果の行には
`"provisional": true` の印が付き、`report` の右端に「仮」と出る

仮の正解と同じ道具の結果を比べると、数は 1.0 に近くなるのが当たり前 その数は精度ではなく、
「前の回から道具の結果が変わったか」の目安にしかならない 本人が直した課題から、本当の精度になる

`draft` をもう 1 度走らせても、作ってある仮の正解は飛ばす（作り直すなら `--force`）
本人が直して取り込んだ正解は、`--force` でも書き換えない

## 正解を直す

`draft` は、外のフォルダの `drafts` に課題ごとの .sme を作る 名前は `<番号>_<課題>.sme`
Sashimono Edit で開いて直し、上書き保存してから `adopt` で取り込む 課題ごとに直す所は次のとおり

| 課題 | 開く物 | 作品の中身 | 直す所 |
|---|---|---|---|
| 無音を削る | `E04_silence.sme` など | 道具が無音を詰めた後のタイムライン | 残すべき所まで削れていたら、クリップの端を伸ばす 残っている無音は分割して消して詰める 話の頭と終わりが欠けていないかを聞いて確かめる |
| 話の区切りで分ける | `E05_talk.sme` | 素材をそのまま置き、長い間の所に「区切り」の目印 | 話題が変わる所に目印を置く 話題の変わらない所の目印は消す 文の区切りではなく話題の区切りを付ける |
| 場面ごとに切る | `E09_scenes.sme` など | 素材をそのまま置き、道具が見つけた切り替わりに「場面」の目印 | 見落とした切り替わりに目印を足し、切り替わりでない所の目印を消す 目印は新しい場面の最初のコマに置く |
| 字幕を付ける | `E04_subtitles.sme` など | 素材に字幕起こしの結果が付いた作品 | 字幕のパネルで、聞き違いの文字と、字幕の頭と終わりの時刻を直す |

- 素材のクリップは動かさない（動かしても目印の位置は素材の秒に直して読むが、迷う元になる）
- 目印の名前と色は数えない どの名前でも 1 つの区切りとして読む
- 別の名前で保存したときは `adopt E09 scenes --from <直した .sme>` で取り込む
- 1 本の 1 課題を直したら、その場で `adopt` してよい 全部を直すまで待たなくてよい

## 数え方

| 課題 | 主な数 | ほかに残す数 |
|---|---|---|
| 無音を削る | `iou` 残した区間の重なり（10ms 刻み） | `agreement` 残す・削るが合った割合 `edge_median` 正解の端ごとに一番近い道具の端までの秒の中央値 |
| 話の区切り | `f1` ±1.0 秒の中で 1 対 1 に組む | `precision` `recall` 道具の段では数えない（道具が無い） |
| 場面ごとに切る | `f1` ±2 フレームの中で 1 対 1 に組む | `precision` `recall` |
| 字幕を付ける | `cer` 文字の誤り率（句読点と空白は数えない） | `edge_f1` 字幕の頭と終わりの一致（±0.5 秒） |

許す幅は `eval/tasks.json` の `tolerances` で変えられる かかった秒は、道具の処理（波形や
場面の解析・字幕起こし）を始めてから答えが出るまでを測る

## 素材を増やす

1. 本人に候補を見せて、使ってよいかを聞く（自分で撮った・作った物だけ）
2. 外のフォルダの `manifest.json` に番号と置き場を足す
3. `eval/tasks.json` の `materials` に番号と課題だけを足す 名前は書かない
4. `draft <番号>` で仮の正解を作り、本人に直してもらう
